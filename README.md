# Portal Web Ikiam - Rediseño, Optimización e Integración Híbrida

¡Hola! En este repositorio comparto el trabajo que realicé para el sitio web de la **Universidad Regional Amazónica Ikiam**. El proyecto nació usando como base una plantilla en HTML5 (llamada PORTO), pero el verdadero reto estuvo en meterle mano al código para optimizarlo por completo y conectar distintas plataformas en un solo lugar, resolviendo así necesidades reales de los profesores, deocentes, alumnos y de la institución en general.

## 🚀 ¿Cómo lo construí y qué hace?

Para lograr un sitio web rápido y completo, decidí combinar la ligereza del HTML básico con herramientas más avanzadas:

* **La base del sitio:** Agarré la plantilla original y la reestructuré a fondo usando HTML5, CSS3 y JavaScript puro. Limpié todo el código que no servía para asegurarme de que la página web sea súper ligera, ordenada y que cargue rápido al navegar.
* **Sección de Investigación con Angular:** Desarrollé y acoplé una aplicación específica para el área de investigación usando el framework Angular. Con esto logré que la sección donde se muestran los proyectos científicos y las publicaciones de los docentes funcione de forma rápida, fluida y moderna.
* **Espacio para las Carreras con WordPress:** Integré WordPress para que cada facultad de la universidad tuviera su propio espacio independiente. La idea principal fue facilitarles la vida a los profesores, permitiendo que ellos mismos puedan subir y administrar los proyectos académicos de sus alumnos sin depender de un programador.

## 🛠️ Herramientas que utilicé

* **Para la estructura y diseño:** HTML5, CSS3 y JavaScript (puro, sin librerías pesadas).
* **Para la aplicación de investigación:** Angular.
* **Para el repositorio de los docentes:** WordPress.

## 💡 El verdadero reto y lo que aprendí

Aunque no empecé el diseño desde cero, adaptar y unir todo esto fue un gran trabajo de arquitectura. Mis mayores logros con este proyecto fueron:

1. **Limpieza y orden:** Pasé muchas horas revisando el código heredado de la plantilla, ordenando las hojas de estilo y mejorando los scripts para que todo funcione como reloj suizo.
2. **Hacer que todo conviva en armonía:** Logré que un sitio web tradicional en HTML5, una aplicación moderna en Angular y el sistema de WordPress se unieran tan bien que el usuario final siente que está navegando en una sola página.
3. **Ayudar a los profesores:** Me enfoqué en dejar un sistema listo y amigable para que los docentes puedan alimentar el contenido de sus carreras de forma segura y sin complicaciones.
